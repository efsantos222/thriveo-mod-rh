# Thriveo Pro - Ecossistema Unificado de RH

Este repositório é a base da plataforma **Thriveo**, consolidando múltiplos módulos de gestão e recrutamento em uma única interface multi-tenant.

## 📦 Arquitetura da Plataforma

A plataforma unificada opera em `thriveo.com.br` e gerencia:
1.  **Multi-Tenancy**: Suporte a múltiplas empresas com branding personalizado (cores/logo).
2.  **Roles & Permissions**: Hierarquia de acesso (Super Admin, Empresa Admin, Usuário, Candidato).
3.  **Módulos Integrados**:
    - `ai-jobs`: Recrutamento e Seleção com IA.
    - `disc`: Avaliação de perfil comportamental (Migração Iniciada).
    - `zbb`: Gestão orçamentária (Roadmap).
    - `pdi`: Plano de Desenvolvimento Individual (Roadmap).

## 🚀 Como Acessar (Admin)

O acesso administrativo à plataforma unificada é feito via parâmetro:
