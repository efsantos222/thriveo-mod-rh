# Portal de Desenvolvimento Profissional

Sistema de gerenciamento de desenvolvimento profissional com suporte a PDIs, coaching e cursos online.

## Requisitos do Sistema
- PHP 8.0+
- MySQL 8.0+
- Servidor Web (Apache/Nginx)

## Estrutura do Projeto
```
/
├── config/         # Configurações do sistema
├── src/           # Código fonte PHP
├── public/        # Arquivos públicos (index.php, assets)
├── templates/     # Templates HTML
└── database/      # Scripts SQL
```

## Instalação
1. Clone o repositório
2. Configure o banco de dados usando os scripts em `/database`
3. Configure as credenciais do banco em `/config/database.php`
4. Inicie o servidor web apontando para a pasta `/public`

## Funcionalidades Principais
- Gestão de usuários e perfis
- Planos de Desenvolvimento Individual (PDI)
- Ferramentas de Coaching
- Sistema de Cursos
- Dashboard Administrativo
- Sistema de Notificações
