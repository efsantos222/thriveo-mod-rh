===================================================================
INSTRUÇÕES DE INSTALAÇÃO:
-------------------------------------------------------------------

1. FAZER UPLOAD DOS ARQUIVOS
   - Copie toda a pasta "php-app" para o seu servidor web
   - Você pode renomear a pasta para o nome que preferir
   - Exemplo: www.seusite.com/virtual-connections/

2. CONFIGURAR PERMISSÕES
   - A pasta "storage/" precisa ter permissões de escrita
   - Execute no terminal (ou via FTP/cPanel):
     chmod 777 storage/
   - Ou via FTP: defina permissões para 777 na pasta storage

3. CONFIGURAR A APLICAÇÃO
   - Abra o arquivo "config.php"
   - Modifique a senha de administrador se desejar:
     define('ADMIN_PASSWORD', 'sysmanager25');
   - Ajuste o timezone se necessário:
     date_default_timezone_set('America/Sao_Paulo');

4. TESTAR A INSTALAÇÃO
   - Acesse: www.seusite.com/caminho-da-pasta/index.php
   - Você deve ver a página inicial do Virtual Connections

ESTRUTURA DE DADOS:
-------------------------------------------------------------------

Os dados são armazenados em arquivos JSON na pasta "storage/":

  - sessions.json: Sessões criadas e participantes
  - game_configs.json: Configurações dos jogos
  - presentations.json: Histórico de apresentações

BACKUP:
  Para fazer backup, copie toda a pasta "storage/"
  Para restaurar, substitua a pasta "storage/" pelo backup

===================================================================
SOLUÇÃO DE PROBLEMAS:
-------------------------------------------------------------------

PROBLEMA: Erro "Permission denied" ao criar sessão
SOLUÇÃO: Verifique permissões da pasta storage/ (deve ser 777)

PROBLEMA: Página em branco
SOLUÇÃO: Ative a exibição de erros do PHP:
         Adicione no início do config.php:
         error_reporting(E_ALL);
         ini_set('display_errors', 1);

PROBLEMA: Sessões não funcionam
SOLUÇÃO: Verifique se o PHP tem permissão para criar sessões
         Verifique a diretiva session.save_path no php.ini

PROBLEMA: JSON não salva
SOLUÇÃO: Verifique permissões de escrita
         Verifique se o módulo JSON está habilitado
