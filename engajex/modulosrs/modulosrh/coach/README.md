# Coaching Tools System

Sistema integrado de ferramentas de coaching para gerenciamento de sessões, avaliações e feedback.

## Funcionalidades Principais

- Gestão de Sessões de Coaching
- Ferramentas de Diagnóstico (DISC/MBTI)
- Gestão de Metas SMART
- Sistema de Feedback Contínuo

## Requisitos

- PHP 7.4+
- MySQL 5.7+
- Servidor Web (Apache/Nginx)

## Instalação

1. Clone o repositório
2. Configure o banco de dados usando o arquivo `database/schema.sql`
3. Configure as credenciais do banco em `config/database.php`
4. Acesse através do seu servidor web
